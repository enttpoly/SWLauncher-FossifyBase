# SW Launcher - Fossify base

SW Launcher é uma versão independente baseada no código aberto do Fossify Launcher.

Este projeto não é o app oficial Fossify Launcher e não deve se apresentar como produto oficial da Fossify.
A base original permanece creditada conforme a licença GPL-3.0 do projeto de origem.

Objetivo do fork:
- identidade própria SW Launcher;
- Material Design 3 / Aurora Glass;
- melhorias de launcher, organização, widgets, dock, gestos e personalização;
- remoção de mensagens/redirects herdados que confundem usuários da versão independente.
